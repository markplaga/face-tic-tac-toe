# Face Tic-Tac-Toe

A playful variation of tic-tac-toe that uses faces or face images in place of traditional X and O markers.

## Concept

The project combines a familiar two-player grid game with personalized or expressive visual markers, making the game more engaging and visually distinctive.

## Status

Early working prototype. The repository is small and still needs fuller setup and gameplay documentation.
